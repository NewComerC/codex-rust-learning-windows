# 03-variables-and-functions · 变量与函数：类型、可变性与返回值

读懂 let/类型推断/mut/shadowing，以及函数末尾表达式作为返回值。

## 涉及的 Rust 概念
let 与类型标注 u32、类型推断、mut、shadowing、if 表达式、尾表达式返回值、() 单元值
